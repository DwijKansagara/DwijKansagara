# Security

Report suspected vulnerabilities privately to **work.dwijkansagara@gmail.com**.

This repository contains public GitHub profile content only. It must never contain API keys, access tokens, private contact details, default credentials, generated source maps, or copied assets without permission. Remote badges must use HTTPS and expose only public aggregate information.

Any future executable or deployed feature must follow the workspace security baseline, including dependency checks, secret scanning, server-side permissions, safe output rendering, strict CORS, rate limiting, privacy review, and live verification.
